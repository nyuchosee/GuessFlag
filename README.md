# 🌍 GuessFlag — угадай флаг

Какая из трёх картинок — флаг загаданной страны? Небольшая учебная игра на SwiftUI помогает потренировать внимательность и заодно вспомнить флаги мира.

## Как играть

1. Посмотри на название страны на экране.
2. Выбери один из трёх флагов.
3. Узнай, верный ли ответ, и нажми **Continue**, чтобы получить следующий вопрос.

За правильный ответ начисляется одно очко. При ошибке счёт не уменьшается. Страны и варианты перемешиваются, а игра продолжается без заданного количества раундов. Счёт хранится в состоянии экрана и при новом запуске начинается с нуля.

В игре используются 11 стран; интерфейс и названия стран — на английском языке.

## Что я здесь изучаю

- **Swift и SwiftUI** — построение экрана из представлений, стеки и кнопки.
- **`@State`** — счёт, текущий вопрос и показ результата.
- **`ForEach`** — создание трёх вариантов ответа.
- **`alert`** — обратная связь после выбора.
- Перемешивание массива и выбор случайного правильного ответа.
- Градиент, материал, формы и изображения из `Assets.xcassets`.

## Запуск

1. Склонируй репозиторий или скачай его через **Code → Download ZIP**:

   ```bash
   git clone https://github.com/nyuchosee/GuessFlag.git
   ```

2. Открой в Xcode файл **`GuessFlag✅/GuessFlag.xcodeproj`**.
3. Выбери схему **GuessFlag** и симулятор iPhone, затем нажми **⌘R**.

В настройках проекта указаны **iOS 15.0** и **Swift 5**; проект создан в Xcode 13.0. На более новой версии Xcode могут понадобиться обновления настроек проекта.
